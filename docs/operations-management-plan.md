# 运行管理落地说明（2026-11-27）

当前完整的页面字段、接口、数据表、执行顺序、权限和验收结果见 [运行管理真实数据链路](operations-data-flow.md)。

## 保持的项目框架

`apps/web/features` 处理接口与状态，`packages/ui/modules` 负责展示，NestJS 独占数据库访问，FastAPI 负责实际模型、检索上下文与工作流执行。运行管理提供跨模块观察和问题定位，配置编辑复用各业务模块。

## 已落地入口

- 聊天输入区仅显示上下文用量环；运行管理会话详情可核对已保存的历史摘要、近期问答与预算。原文轮数遵循智能体配置，较早内容增量压缩为摘要，原始消息保留。详见 [上下文压缩改造](conversation-context-compression.md)。
- 知识库文件统一使用已有解析器，支持文本、TXT/JSON、PDF、Word、Excel、PPT、Markdown/CSV/HTML 和图片。运行管理支持真实原文件/解析文本/切片查看、下载、失败重试和确认删除。
- 文件处理阶段和耗时来自数据库处理历史；知识库 Token 曲线来自本地模型 tokenizer；检索结果、相似度、引用采用和失败来自实际业务请求。
- “集成与调用”展示真实插件、工作流、API 密钥和模型概览，并提供 API 请求、按密钥统计、插件参数/结果、工作流节点结果明细。
- 运行概览纳入真实文件处理和聊天记录，聊天统计读取完整分页；没有数据时保持空态，未采集的历史字段不生成补位数字。

## 使用边界

上下文余量是明确标注的基础上下文保守估算，与供应商实际报告的模型 Token 分开。待发送问题、附件、工具和检索片段在执行时另计。历史从未保存的精确用量、来源和参数不能可靠重建。

文件大小限制：TXT/JSON 1 MB，Markdown/CSV/HTML 2 MB，图片 5 MB，PDF/Office 20 MB。图片需已配置的 OCR 或视觉服务；扫描 PDF 当前没有 OCR 回退。

任何会产生外部副作用的工具调用、工作流重跑均应经正常业务入口执行，运行管理不会因查看记录而自动重跑。
