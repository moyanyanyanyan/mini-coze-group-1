## 一、联调目标（一句话）

**网页聊天和公开 API 两条入口，走我 NestJS 的同一条 ChatService 路径，从王一恒的 Runtime 拿到真实 SSE 流，全流程跑通并留下证据（截图/录屏/curl 记录）。**

对应验收标准（组长 Week 2 表）：
1. 网页聊天页发消息，SSE 打字机效果出字
2. 用 API Key + Bearer 调公开流式接口，同样收到 SSE 流
3. 两条入口走的是**同一条 Runtime 调用路径**（抽成内部 service，不复制两份）

## 二、职责边界（谁准备什么）

| 环节 | 韦淇元（NestJS） | 王一恒（FastAPI Runtime） |
|---|---|---|
| 鉴权 | JWT / API Key 校验，解析 actor，401/403 | ❌ 不做，信任 NestJS 传来的 actor |
| 入口接口 | `POST /api/agents/:agentId/chat/stream`（网页）、`POST /v1/agents/:agentId/chat`（公开） | ❌ 不暴露给浏览器 |
| 上下文 | 生成 runId / userMessageId / assistantMessageId；读历史（**≤20 条 = 10 个完整对话对**，显式排除本轮、只取 completed）；读 AgentConfig 快照；组装 RuntimeRequest | 接收并校验 RuntimeRequest，做最终模型上下文预算检查 |
| 生成 | ❌ 不碰模型 | 调 DeepSeek，知识库检索，工具循环 |
| SSE 转发 | 随到随转发 delta；knowledge.result 内部版→对外版脱敏 | 吐统一事件（7 种），seq 递增 |
| 持久化 | 用户消息先存；助手消息 running 占位 → 终态一次性写；**保存成功才转发 run.completed** | ❌ 不写库 |
| 中断 | 取消对 FastAPI 的请求，标 cancelled，保留 partial | 收到取消后停止上游调用、释放资源 |
| 并发 | 同会话运行中重复提交 → 409 CONVERSATION_BUSY | — |

## 三、接口契约（按王一恒 10.13 稿执行，冻结前不动字段）

### 3.1 NestJS → FastAPI（内部）

| 项 | 值 |
|---|---|
| 路径 | `POST /internal/runtime/run`（聚合）· `POST /internal/runtime/stream`（SSE） |
| 认证 | `Authorization: Bearer <INTERNAL_SERVICE_TOKEN>`（方案待组长定，R3；代码先预留） |
| 请求体 | RuntimeRequest：`runId, actor:{id}, conversationId, userMessageId, assistantMessageId, agentConfig{id,revision,name,systemPrompt,model,temperature,maxTokens,knowledgeBaseIds,pluginIds}, history[], message`；`history` 项为 `{role, id, content}`，最多 20 条 = 10 个完整对话对（v1.1） |
| run 返回 | RuntimeResult：`content, citations[], toolResults[], finishReason, usage` |
| stream 返回 | SSE，事件见 3.3；载荷为**扁平信封 + 嵌套 `data`**（v1.1） |

### 3.2 浏览器 → NestJS（两条入口，同一事件协议）

| 入口 | 路径 | 鉴权 | 请求体 |
|---|---|---|---|
| 网页 | `POST /api/agents/:agentId/chat/stream` | JWT（Bearer） | `{ "conversationId": "可选，省略=新建", "message": "必填非空" }` |
| 公开 | `POST /v1/agents/:agentId/chat` | Bearer API Key | 同上 |

### 3.3 SSE 事件表（7 种；扁平信封 + 嵌套 data，v1.1）

信封：`{runId, conversationId, seq, timestamp, type, data}`，`type` 与 SSE 的 `event:` 行一致，业务载荷一律放 `data` 内。

| 事件 | data 关键字段 | 前端行为 |
|---|---|---|
| run.started | assistantMessageId | 占位气泡→"正在生成"，显示停止按钮 |
| knowledge.result | 内部版 `status: matched/no_match + chunks[]`（`content`/`score`/`citation`）；**对外脱敏为 `status + citations[]`（去正文/score/position）** | 展示来源标签 / "未检索到" |
| message.delta | content | 增量追加（不重建整条消息） |
| tool.started | toolCallId, toolName, arguments（转发前脱敏） | 工具卡"执行中" |
| tool.completed | PluginToolResult：`toolCallId, toolName, status: succeeded\|failed, output?, error?`（**output 为结构化对象；不用 ok 字段**） | 工具卡成功/失败；业务失败回填模型不终止 |
| run.completed | RuntimeResult：`{runId, conversationId, assistantMessageId, status, content, citations, toolResults, finishReason, usage}`（content 须 == 全部 delta 拼接） | 结束 loading，恢复发送 |
| run.failed | code, message, retryable | 保留 partial，显示失败+重试 |

规则：completed/failed 唯一终止、互斥；连接关闭无终止事件 = 显示中断；同会话并发 409；心跳 `: ping` 每 15s 一次且**不占 seq**；`cancelled` 与 `failed` 轮次均不进下一轮 history；NestJS 保存成功后才转发 `run.completed`。

### 3.4 错误码（建流前 HTTP，建流后流内 run.failed）

| 错误码 | HTTP | 触发方 | 说明 |
|---|---|---|---|
| INVALID_REQUEST | 400 | NestJS | 建流前校验失败，**不调 Runtime** |
| UNAUTHORIZED | 401 | NestJS | — |
| FORBIDDEN | 403 | NestJS | — |
| NOT_FOUND | 404 | NestJS | — |
| CONVERSATION_BUSY | 409 | NestJS | 同会话并发 |
| MODEL_NOT_CONFIGURED | 503 | Runtime | Key 未配置 |
| MODEL_TIMEOUT | 504 | Runtime | 模型超时 |
| MODEL_RATE_LIMITED | 503 | Runtime | 限流 |
| MODEL_UNAVAILABLE | 502 | Runtime | 模型不可用 |
| KNOWLEDGE_UNAVAILABLE | 502 | Runtime | 检索失败/超时，**不得伪装成 no_match** |
| TOOL_NOT_ALLOWED | 400 | Runtime | 由插件侧 `TOOL_NOT_FOUND` 映射，终止本轮 |
| TOOL_INVALID_ARGUMENTS | 400 | Runtime | 由插件侧 `INVALID_ARGUMENTS` 映射，终止本轮 |
| TOOL_EXEC_ERROR / TOOL_TIMEOUT | 流内 | Runtime | 业务失败 → **回填模型**，不终止本轮 |
| RUN_TIMEOUT | 504 | Runtime | 整轮超时 |
| RUNTIME_UNAVAILABLE | 503 | NestJS | Runtime 内部凭证失败/服务不可用，**不得透传 401 当作用户登录失效** |
| PERSISTENCE_FAILED | 500 | NestJS | 保存失败，**绝不发 run.completed** |

HTTP 错误体沿用 `{ statusCode, message, path, timestamp }`；是否增补 `code` 字段 = 待决策项 D3。

## 五、联调场景清单（10.22~10.24 逐条打勾，留证据）

### A. 基础链路（先跑通这条再谈其他）
- [ ] A1 新会话首条消息：200 → run.started → delta×N → run.completed；页面打字机出字
- [ ] A2 run.completed 的 content == 全部 delta 拼接
- [ ] A3 刷新页面：历史完整回来，状态为 completed
- [ ] A4 旧会话继续发：RuntimeRequest.history 含此前对话，**当前消息只出现一次**
- [ ] A5 会话列表：多会话创建、切换、互不串历史

### B. SSE 解析健壮性
- [ ] B1 一个网络分块含多个事件
- [ ] B2 一个事件被拆到两个分块（含 UTF-8 中文被切半）
- [ ] B3 seq 严格递增；心跳注释（SSE `:`）不进 seq

### C. 中断与并发
- [ ] C1 生成中点停止：消息标 cancelled，partial 文本保留，UI 显示"已停止"
- [ ] C2 停止后立刻重发：新 runId，正常走完
- [ ] C3 同会话运行中再发：409 CONVERSATION_BUSY
- [ ] C4 已停止的轮次不进入下一轮 history

### D. 错误与降级
- [ ] D1 未登录调网页接口：401，不发模型请求
- [ ] D2 用别人的 conversationId / agentId：403 或 404（按资源隐藏策略）
- [ ] D3 模拟模型超时：流内 run.failed(MODEL_TIMEOUT)，前端保留 partial + 重试按钮
- [ ] D4 模拟保存失败（断库）：对外发 PERSISTENCE_FAILED，**绝不发 run.completed**（R6）
- [ ] D5 空消息 / 超 8000 字符：400 INVALID_REQUEST，不调 Runtime

### E. 知识库与工具（依赖管逸恬/朱晋亨联调进度，可后置 10.23~10.24）
- [ ] E1 无绑定：直接生成，不出空工具卡
- [ ] E2 命中：knowledge.result(matched)，来源标签可展示，**对外事件无正文**（脱敏生效）
- [ ] E3 未命中：no_match，继续正常回答
- [ ] E4 检索服务挂：KNOWLEDGE_UNAVAILABLE 终止，不伪装成 no_match
- [ ] E5 工具：tool.started → tool.completed 配对（toolCallId），失败卡不标成功
- [ ] E6 非法工具/参数：TOOL_NOT_ALLOWED 终止本轮

### F. 公开 API 一致性（10.24）
- [ ] F1 API Key 生成 + 只展示一次
- [ ] F2 Bearer API Key 调 `POST /v1/agents/:agentId/chat`：与网页**同一套事件**、同一条 ChatService 路径
- [ ] F3 无效 Key：401；未发布渠道：403/404
- [ ] F4 curl 全程录屏/贴记录，作为验收证据
