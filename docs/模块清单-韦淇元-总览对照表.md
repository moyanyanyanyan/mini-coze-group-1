## 零、一句话总览

**5 个大模块 · 30 个小模块。** 其中 4 个是「功能大模块」（A 认证与用户 / B 会话与历史 / C 流式对话 / D 发布与公开 API），
外加 1 个「横向大模块」E（契约与对齐）——E 不产生新页面，但你**必须先交**，因为全组都在等它。

```
                    ┌──────────── E. 契约与对齐（横向，最优先）────────────┐
                    │  CurrentUser · 401/403 · Conversation/Message        │
                    │  SSE 事件表 · API Key 与公开 API 契约                │
                    └───────────────────┬─────────────────────────────────┘
                                        │ 被所有人消费
   A. 认证与用户 ──► B. 会话与历史 ──► C. 流式对话 ──► D. 发布与公开 API
   （地基，别人      （容器，存消息）   （核心，打字机）  （出口，对外 API）
    都依赖你）
```

**依赖顺序不能反**：没有 A 的 `CurrentUser`，B 不知道会话归谁；没有 B，C 的消息没地方存；没有 C，D 的公开接口没有东西可调。

## 一、A. 认证与用户（8 个小模块）— 全组地基，优先级最高

> 一句话：让人能进来，并且让后端每个接口都知道"现在是谁"。

| 编号 | 小模块 | 具体要做什么 | 产出位置 | 依赖/协作 | 状态 |
|---|---|---|---|---|---|
| **A1** | User 数据模型 | Prisma 建 `User` 表：`id`、`username`、`passwordHash`、`email`、`googleId`、`avatar`、`createdAt`；跑通第一条 migrate | `apps/backend/prisma/schema.prisma` | 数据库由全组共用，`ownerId` 外键要跟**陈弘毅**（Agent）对齐 | ⬜ |
| **A2** | 用户名密码注册 | `POST /auth/register`：DTO 校验（用户名长度/密码强度）→ 查重 → **bcrypt 哈希**（saltRounds 10~12，绝不存明文/MD5）→ 落库 | `apps/backend/src/auth/` | — | ⬜ |
| **A3** | 用户名密码登录 + 签发 JWT | `POST /auth/login`：校验密码 → 签 JWT（payload 放 `sub=userId`、`username`、`type='user'`，有效期 **7 天**，MVP 不做 refresh token） | 同上 | — | ⬜ |
| **A4** | JWT 守卫与公开标记 | `passport-jwt` + `JwtStrategy` + `JwtAuthGuard`；`@Public()` 装饰器标公开接口（登录、注册、health、`/v1`） | `apps/backend/src/auth/guards|decorators` | — | ⬜ |
| **A5** | CurrentUser 注入 | 自定义 `@CurrentUser()` 装饰器，controller 里直接拿到 `{ id, username, avatar, type }` | `apps/backend` + **类型放 `packages/shared`** | 类型定义要给全组（见 E1） | ⬜ |
| **A6** | 鉴权错误格式 | 401 未登录 / 403 无权限，统一 JSON：`{ statusCode, code, message, path, timestamp }` | `apps/backend/src/common/http-exception.filter.ts`（已有文件，扩） | 与组长确认是否增补 `code` 字段（决策项 D3） | 🟡 过滤器已有，鉴权码未接 |
| **A7** | Google OAuth | `GET /auth/google` 跳转 → 回调拿 `code` → **后端**换 token → 查/建用户（按 `googleId` 或 email 绑定）→ 发自家 JWT | `apps/backend/src/auth/` | 国内网络需代理；**卡壳就降级**，保证用户名密码先通 | ⬜（可砍到 Week 3） |
| **A8** | 前端登录态 | 登录页/注册页接真实接口、token 存储（localStorage 或 cookie）、刷新后仍在、**路由守卫**（未登录跳 `/login`）、退出登录清 token | `apps/web/src/pages/LoginPage.tsx`、`RegisterPage.tsx`、`App.tsx` | — | 🟡 页面壳已有，**未接任何接口**（全仓搜不到 fetch/localStorage） |

**A 块验收口径（组长验收条 1）**：注册 → 登录 → 拿 JWT → 页面读出当前用户 → 点退出清空登录态；Google OAuth 网络不通时说明降级。

## 三、C. 流式对话（7 个小模块）— 最难的一块，本周核心

> 一句话：把用户消息送进 Runtime，把流式结果一个字一个字吐到页面上。

| 编号 | 小模块 | 具体要做什么 | 产出位置 | 依赖/协作 | 状态 |
|---|---|---|---|---|---|
| **C1** | RuntimeClientService | 后端 fetch 调 `POST {AGENT_SERVICE_URL}/internal/runtime/stream`，`Accept: text/event-stream` + `Bearer INTERNAL_SERVICE_TOKEN`；按 `\n\n` 分段解析 SSE，**处理分块边界与 UTF-8 中文被切半**，过滤 `: ping` 心跳 | `apps/backend/src/chat/runtime-client.service.ts` | **王一恒**（Runtime）提供事件流；代码骨架已在联调契约里写好，可直接抄 | 🟡 契约文档里有完整示例代码 |
| **C2** | ChatService（唯一路径） | 生成 `runId`/`userMessageId`/`assistantMessageId` → 用户消息**先落库** → 读 history（**≤20 条、正序、不含当前消息、不含 cancelled 轮次**）→ 读 AgentConfig 快照 → 组装 `RuntimeRequest` → 消费事件 → **终态一次性落库** | `apps/backend/src/chat/chat.service.ts` | ⚠️ **网页和公开 API 都调它，绝不复制两份**（验收硬标准） | 🟡 契约文档里有装配段示例 |
| **C3** | 网页流式接口 | `POST /api/agents/:agentId/chat/stream`（JWT 鉴权），随到随转发 delta；`knowledge.result`/`tool.started` 对外前**脱敏**（去正文、去敏感参数） | `apps/backend/src/chat/` | — | ⬜ |
| **C4** | 中断生成 | 前端「停止」→ 后端 AbortController 断连 → 消息标 `cancelled`，**保留已产出的 partial 文本**；该轮不进下一轮 history（场景 C4） | 后端 + 前端按钮 | 与王一恒确认「停止=断连、不发终止事件」 | ⬜ |
| **C5** | 并发控制 | 同一会话运行中重复提交 → **409 CONVERSATION_BUSY**（控制在 NestJS 侧，Runtime 不用做） | `apps/backend/src/chat/` | — | ⬜ |
| **C6** | 前端 SSE 消费 | 用 `fetch + ReadableStream`（**不用 EventSource**，因为它带不了 Authorization 头）；增量追加不重建整条消息；打字机渲染、停止按钮、失败重试 UI | `apps/web/src/pages/`（聊天页） | — | ⬜ |
| **C7** | 本地 Mock Runtime | 起一个本地假服务吐 3~5 个假事件，`.env` 里切 `AGENT_SERVICE_URL`（真 8000 / mock 9999），**不阻塞王一恒** | `apps/backend`（或独立 mock 脚本） | — | ⬜ |

**C 块关键规则（背下来，联调时按这些打勾）**：
- `run.completed` / `run.failed` 是**唯一终止事件**，互斥且最多一次；连接断开无终止事件 = 按中断处理
- **保存成功才把 `run.completed` 转发给浏览器**，保存失败发 `run.failed(PERSISTENCE_FAILED)`，**绝不发 completed**
- `seq` 从 1 严格递增，心跳不占 seq
- 7 种事件：`run.started` / `knowledge.result` / `message.delta` / `tool.started` / `tool.completed` / `run.completed` / `run.failed`

## 八、Week 2 三条验收标准（对着这条自测）

- [ ] **3. 密钥只放环境变量**
